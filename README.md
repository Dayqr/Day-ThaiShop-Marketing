## 🚀 เริ่มยังไง

### ครั้งแรกสุด (ทำครั้งเดียว)
1. อ่าน `docs/01-STRATEGY.md` จนจบ — จะได้รู้ว่ากำลังทำอะไรอยู่
2. ตัดสินใจ 3 เรื่องที่ค้างอยู่ท้ายไฟล์นั้น (ชื่อช่อง / ราคา / ประเทศแรก)
3. เปิดช่อง YouTube + Facebook Page

### ทุกครั้งที่จะทำคลิป
```
1. เปิด content/topic-bank.md → เลือกหัวข้อ
2. บอก Claude: "ทำคลิปหัวข้อที่ 12"
3. Claude อ่าน docs/03-HOOK-FORMULAS.md → เขียนสคริปต์ลง scripts/
4. รัน pipeline สร้างวิดีโอ
5. อัปเดต content/status.md
```

## ⚠️ กฎที่ห้ามลืม

1. **ห้าม commit API key / token / ไฟล์ credentials** ลง repo นี้ (ดู `.gitignore`)
2. **ห้ามโชว์ตัวเลขรายได้ส่วนตัวของคุณเด** ในคลิปหรือโฆษณาทุกชิ้น
3. **ห้ามด่า/แขวะหมอนวดหรือพนักงาน** ในที่สาธารณะ — เจ้าของร้านกับหมอนวดอยู่กลุ่ม FB เดียวกัน
4. **เรื่องวีซ่า / ภาษี / กฎหมายแรงงาน** — เล่าประสบการณ์ได้ แต่ต้องพ่วง "ควรเช็คกับ migration agent / accountant" ทุกครั้ง
5. **ห้ามสัญญาตัวเลขรายได้เฉพาะเจาะจง** ให้ลูกค้า ("เพิ่ม $5,000/เดือน") — ใช้ช่วงหรือ % แทน
