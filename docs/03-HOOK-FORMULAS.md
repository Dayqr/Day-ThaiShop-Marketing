## ส่วนที่ 1 — HOOK (3 วินาทีแรก คือทั้งหมด)

### กฎเหล็ก
```
❌ ห้ามขึ้นต้นด้วย: "สวัสดีครับ" · "วันนี้จะมาสอน" · "หลายคนถามมาว่า" · "ผมชื่อ..."
✅ ต้องขึ้นต้นด้วย: ปัญหา / ตัวเลข / ความเสียใจ / คำถามที่เขาแอบสงสัย
```

### 6 สูตร Hook ที่ใช้ได้จริง

**สูตร A — ปัญหาที่เจ็บ** (ใช้บ่อยสุด)
> "ขายทุกวัน แต่ไม่รู้ว่าเงินหายไปไหน"
> "ร้านเต็มทุกวัน แต่สิ้นเดือนไม่เหลือเงิน"
> "หาพนักงานไทยไม่ได้ ทุกร้านแย่งกันหมด"

**สูตร B — ความเสียใจในอดีต**
> "ถ้าย้อนเวลากลับไปได้ ผมจะไม่เซ็นสัญญาเช่าฉบับนั้น"
> "5 ปีแรกผมคิดผิดเรื่องนี้ตลอด"

**สูตร C — ตัวเลขที่ตกใจ**
> "ร้านนวดคิว $60 เจ้าของเหลือจริง $11"
> "1 รีวิวแย่ = เสียลูกค้า 94 คน"
> "เพิ่ม 1 ดาวใน Google = รายได้เพิ่ม 7%"

**สูตร D — ลิสต์ตัวเลข**
> "5 ตัวเลขที่ต้องรู้ก่อนเซ็นสัญญาเช่าร้าน"
> "3 อย่างที่ทำให้ร้านนวดไทยดูไม่น่าเข้า"

**สูตร E — เปรียบเทียบ/ขัดใจ**
> "ร้านคุณ 3.9 ดาว ร้านข้างๆ 4.7 ดาว — ใครได้ลูกค้า?"
> "ทำไมร้านที่ยอดขายดีที่สุดในย่าน ถึงปิดตัว"

**สูตร F — ความจริงที่ไม่มีใครบอก**
> "ไม่มีใครบอกคุณว่าค่าธรรมเนียมบัตรกินไปเท่าไหร่"
> "เรื่องที่เจ้าของร้านไทยรู้ตอนสายเกินไป"

### เช็ค Hook ก่อนใช้
```
□ ยาวไม่เกิน 12 คำ
□ ไม่มีคำว่า "สอน" "แนะนำ" "เทคนิค"
□ อ่านแล้วเจ้าของร้านต้องคิดว่า "นี่มันเรื่องกูเลย"
□ ตรงกับเนื้อหาจริง (ไม่ clickbait)
```

## ส่วนที่ 2 — โครงสร้างสคริปต์

### Shorts / Reels (60 วินาที)
```
0-3 วิ    HOOK       ตัวหนังสือใหญ่กรอบดำ + พูดพร้อมกัน
3-8 วิ    EMPATHY    "ผมเคยเจอแบบนี้..." / "เจ้าของร้านหลายคนถามผมเรื่องนี้"
8-40 วิ   BODY       3-5 ข้อ มีตัวเลขจริงทุกข้อ
40-52 วิ  PUNCH      สรุป 1 ประโยคที่จำได้
52-60 วิ  CTA        (ดูส่วนที่ 3)
```

### Long-form (8-15 นาที)
```
0-15 วิ    HOOK + บอกว่าจะได้อะไรจากคลิปนี้
15-45 วิ   เล่าเคสจริง 1 เคส (ทำให้เชื่อว่าเราเข้าใจ)
45 วิ-เนื้อ  แบ่งเป็น 4-6 ช่วง แต่ละช่วงมีหัวข้อบนจอ
             ⚠️ ทุก 60-90 วิ ต้องมี pattern interrupt (เปลี่ยนภาพ/เสียง/มุมกล้อง)
ท้าย 60 วิ  สรุปเป็นข้อๆ + CTA
```

### กติกาเหล็ก 5 ข้อ (ทุกคลิป)
1. **ตัวหนังสือบนจอตลอดเวลา** — 80% ของคนดูปิดเสียง
2. **1 คลิป = 1 เรื่อง** ห้ามยัด
3. **ตัวเลขจริงเสมอ** — "$4,200/เดือน" ชนะ "ค่าเช่าแพง"
4. **ประโยคสั้น** — พูดเหมือนคุยกับเพื่อน ไม่ใช่อ่านรายงาน
5. **ห้ามเกินความยาวที่กำหนด** — Shorts ≤ 60 วิ, Reels ≤ 90 วิ

## ส่วนที่ 3 — CTA (ต้องเหมือนกันทุกคลิป)

> **ความสม่ำเสมอสร้างยอด ไม่ใช่ความหลากหลาย** — อย่าเปลี่ยน CTA ไปมา

### CTA แบบ A — เก็บคอมเมนต์ (ใช้กับ Shorts/Reels)
```
"อยากได้ [ของฟรี] พิมพ์คำว่า '[คำเดียว]' ในคอมเมนต์นะครับ เดี๋ยวส่งให้"
```
ตัวอย่าง: พิมพ์ "ต้นทุน" / "รีวิว" / "เช็คลิสต์"

**ทำไมได้ผล:** คนคอมเมนต์ = อัลกอริทึมดันต่อ + ได้ lead ตรงๆ

### CTA แบบ B — ไป LINE (ใช้กับ long-form)
```
"ถ้าอยากคุยเรื่องร้านคุณโดยเฉพาะ ทัก LINE @xxxxx ได้เลยครับ คุยฟรี 15 นาที ไม่มีขายของ"
```

### กฎ CTA
```
✅ ให้ของฟรีก่อนเสมอ — ไม่ขอก่อนให้
✅ บอกชัดว่า "ไม่มีเซลส์โทรตาม"
❌ ห้าม hard sell
❌ ห้ามใส่ลิงก์ในโพสต์ Facebook → ใส่ในคอมเมนต์แรกแทน (FB ลดการมองเห็นโพสต์ที่มีลิงก์)
```

## ส่วนที่ 4 — TITLE (ชื่อคลิป)

### สูตร
```
[ปัญหา/ตัวเลข] + [กลุ่มเป้าหมาย] + [ผลลัพธ์]
```

ตัวอย่างดี:
- ✅ "ร้านนวดไทยในออสเตรเลีย ทำไมคิว $60 แต่เหลือจริงแค่ $11"
- ✅ "5 ตัวเลขที่ต้องรู้ก่อนเซ็นสัญญาเช่าร้านในออสเตรเลีย"
- ✅ "ร้านอาหารไทย VS ร้านนวดไทย ในออสเตรเลีย เปิดอะไรดีกว่า?"

ตัวอย่างแย่:
- ❌ "เทคนิคบริหารร้าน" (กว้าง ไม่มีตัวเลข ไม่มีที่)
- ❌ "สิ่งที่คุณต้องรู้!!!" (clickbait ไม่บอกอะไรเลย)

### กฎ
```
□ ต้องมีคำว่า "ออสเตรเลีย" หรือ "ร้านไทย" (เพื่อ SEO + คัดคนดูในไทยออก)
□ ยาว 40-60 ตัวอักษร (มือถือตัดที่ ~60)
□ ตัวเลขในชื่อ = CTR สูงกว่า
```

## ส่วนที่ 5 — THUMBNAIL

```
□ หน้าคน (คุณเด/avatar) แสดงอารมณ์ชัด — ตกใจ / สงสัย / จริงจัง
□ ตัวหนังสือไม่เกิน 5 คำ ตัวใหญ่มาก
□ สีตัดกัน (เหลือง/แดง บนพื้นเข้ม)
□ ต้องอ่านออกตอนย่อเหลือขนาดนิ้วโป้ง
□ ทำ 2-3 แบบต่อคลิป → A/B test
```
