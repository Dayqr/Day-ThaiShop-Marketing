# 05 — AI Avatar (หน้าคุณเดพูดเอง)

> เป้าหมาย: ทำคลิปที่มี **หน้าคุณเดพูด** ได้โดยไม่ต้องยืนถ่ายทุกคลิป
> เพราะกลยุทธ์ข้อสำคัญของเพจต้นแบบคือ **"มีหน้าคนพูด = คนเชื่อ"**

---

## 1. ทำไมต้องมีหน้าคน

เพจ "ขายดีไปด้วยกัน" (668K) ทุกคลิปมีหน้าคนพูด + ถ่ายในร้านจริง
→ คนเชื่อว่า "พี่คนนี้เคยเจ็บมาก่อน" ไม่ใช่กูรูอ่านหนังสือมาเล่า

คลิปที่มีแต่ stock footage + เสียง TTS = ดูเหมือนโฆษณา คนเลื่อนผ่าน

**แต่** ถ่ายเองทุกคลิปวันละ 1-2 คลิป = ทำไม่ไหวในระยะยาว
→ **ทางออก: ถ่ายจริงบางคลิป + AI Avatar บางคลิป**

---

## 2. เปรียบเทียบเครื่องมือ

| เครื่องมือ | ทำอะไรได้ | ภาษาไทย | ราคา | เหมาะกับ |
|---|---|---|---|---|
| **HeyGen** | สร้าง avatar จากวิดีโอตัวเอง 2 นาที, 4K | ✅ ดี | ฟรี (จำกัด) / ~$24-29/เดือน | ⭐ แนะนำเริ่มที่นี่ |
| **Synthesia** | 60+ templates, avatar ตัวเอง | ✅ พูดไทยได้ | ~$22-29/เดือน | ทางเลือกที่ 2 |
| **D-ID** | ทำจากรูปนิ่ง 1 รูป | ⚠️ พอใช้ | ~$5-49/เดือน | ถูกสุด แต่ปากไม่ค่อยตรง |
| **Hedra** | ทำจากรูป + เสียง | ⚠️ พอใช้ | ฟรี (จำกัด) / ~$10+ | ทดลองฟรีได้เยอะ |
| **ถ่ายเอง** | ธรรมชาติที่สุด | ✅ | ฟรี | คลิปสำคัญ / เคสจริง |

> ⚠️ **ต้องขออนุญาตคุณเดก่อนสมัครทุกเจ้า** — มีค่ารายเดือน (กฎใน CLAUDE.md)

## 3. แผนที่แนะนำ — แบบผสม (ประหยัดสุด คุณภาพดีสุด)

```
┌─────────────────────────────────────────────────────────┐
│  ถ่ายจริง (คุณเดยืนพูด)          →  20% ของคลิป           │
│  · เคสจริง / ไปถ่ายในร้าน                                │
│  · คลิปสำคัญ / คลิปเปิดตัว                                │
│  · Behind the scenes                                     │
├─────────────────────────────────────────────────────────┤
│  AI Avatar (หน้าคุณเด)           →  50% ของคลิป           │
│  · คลิปให้ความรู้ประจำวัน                                  │
│  · ตอบคำถามที่คนถามบ่อย                                   │
├─────────────────────────────────────────────────────────┤
│  ไม่มีหน้าคน (stock + ตัวหนังสือ)  →  30% ของคลิป          │
│  · คลิปที่เป็นตัวเลข/ตาราง/เปรียบเทียบ                     │
└─────────────────────────────────────────────────────────┘
```

**อย่าใช้ AI Avatar 100%** — คนดูจับได้ และความน่าเชื่อถือจะพัง

## 4. ขั้นตอนทำ (ครั้งแรก)

### ① ถ่ายวิดีโอต้นแบบสำหรับสร้าง avatar
```
□ ยืนหรือนั่งหน้ากล้อง พื้นหลังเรียบ (ผนังสีเดียว)
□ แสงส่องหน้าตรง ไม่ย้อนแสง
□ พูดต่อเนื่อง 2-3 นาที (พูดอะไรก็ได้ เช่น แนะนำตัว)
□ ขยับหน้า/มือแบบธรรมชาติ ไม่นิ่งเป็นหุ่น
□ ถ่าย 1080p ขึ้นไป
□ เก็บไฟล์ไว้ที่ assets/avatar-source/ (❌ ห้าม commit ขึ้น git — ไฟล์ใหญ่)
```

### ② อัปเข้า HeyGen → สร้าง Instant Avatar
- ใช้เวลาประมวลผลราว 10-30 นาที
- ได้ avatar ID มา 1 อัน → เก็บไว้ใน `.env`

### ③ เรื่องเสียง — เลือก 1 ใน 2
| ทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| **A. Google TTS** (ที่ใช้อยู่แล้ว) | ฟรี · ทำงานร่วมกับ pipeline เดิมได้เลย | ไม่ใช่เสียงคุณเด ฟังออกว่าเป็น AI |
| **B. โคลนเสียงคุณเดใน HeyGen** | เป็นเสียงคุณเดจริง เนียนกว่ามาก | รวมอยู่ในแพ็กเกจ HeyGen (ไม่ต้องจ่ายเพิ่ม) |

→ **แนะนำ B** ถ้าสมัคร HeyGen อยู่แล้ว (ไม่ต้องจ่ายเพิ่ม และเนียนกว่าเยอะ)
→ ❌ **ห้ามใช้ ElevenLabs** (กฎเดิม — แพงเกิน)

### ④ ต่อเข้า pipeline
สร้าง `pipeline/src/avatar_video.py`:
```
รับ: ข้อความสคริปต์
→ เรียก HeyGen API (avatar_id + voice_id)
→ ได้วิดีโอ avatar พูด (พื้นหลังโปร่งใส/เขียว)
→ ส่งต่อให้ video_assembler.py ซ้อนบนคลิป stock
→ ใส่ตัวหนังสือไทยทับ
```

## 5. เลย์เอาต์คลิปที่แนะนำ (Reels 9:16)

```
┌─────────────────┐
│  ตัวหนังสือ hook  │  ← กรอบดำตัวขาว (ท่อน 0-3 วิ)
│   กรอบดำ         │
├─────────────────┤
│                 │
│   คลิป stock    │  ← Pexels / Veo (ภาพประกอบเนื้อหา)
│   หรือภาพร้าน    │
│                 │
├─────────────────┤
│  [avatar คุณเด]  │  ← ครึ่งตัว มุมล่าง หรือเต็มจอสลับไปมา
│                 │
├─────────────────┤
│  subtitle ไทย   │  ← จับเวลาคำ (transcriber)
└─────────────────┘
```

## 6. ⚠️ ข้อควรระวังเรื่อง AI Avatar

| เรื่อง | ต้องทำ |
|---|---|
| **ความซื่อสัตย์** | ถ้าคนถามตรงๆ ว่าใช่ AI ไหม → **ตอบตามจริง** ห้ามปฏิเสธ |
| **YouTube policy** | YouTube ต้องการให้ระบุว่าเนื้อหาสร้างด้วย AI (ช่อง "Altered content") → **ติ๊กทุกครั้งที่ใช้ avatar** |
| **หน้าคนอื่น** | ❌ ห้ามใช้หน้าคนอื่นเด็ดขาด แม้แต่ avatar สำเร็จรูปที่หน้าเหมือนคนจริง — ใช้หน้าคุณเดเท่านั้น |
| **เสียงคนอื่น** | ❌ ห้ามโคลนเสียงใครนอกจากคุณเด |
| **คลิปเคสจริง** | ❌ ห้ามใช้ avatar เล่าเรื่องที่อ้างว่าเป็นเคสจริง โดยที่ไม่ได้เกิดขึ้นจริง |
| **ไฟล์ต้นฉบับ** | เก็บใน `assets/avatar-source/` และใส่ `.gitignore` — ไฟล์ใหญ่ + เป็นข้อมูลส่วนตัว |

## 8. ทางเลือกถ้ายังไม่อยากจ่าย

เริ่มแบบ **ฟรี 100%** ก่อนได้:
1. ถ่ายคลิปตัวเอง **1 ครั้ง เก็บ 20-30 ท่อน** (นั่งพูด hook หลายๆ แบบ, ท่าทางพยักหน้า, หัวเราะ, ชี้มือ)
2. เก็บไว้เป็นคลัง B-roll ของหน้าตัวเอง
3. ทุกคลิปใหม่ → ใช้เสียง TTS + ตัดคลิปหน้าตัวเองจากคลังมาแทรก
4. ได้ 70% ของผลลัพธ์ ที่ต้นทุน $0

→ ถ้าเวิร์ก ค่อยอัปเกรดไป HeyGen ทีหลัง
